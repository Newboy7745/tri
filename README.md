# Tri by Khalid

Application de tri et d'inventaire des affaires de la maison (PWA).

- Photo → chaque objet est isolé, nommé précisément et compté
- Fiches modifiables, listes déroulantes qui apprennent les nouvelles valeurs
- Onglets par catégorie, sélection multiple, suivi coloré (à trier → à faire → en cours → terminé)

Les données restent sur le téléphone (IndexedDB). Pense à exporter une sauvegarde depuis Réglages.
L'analyse automatique utilise une clé API Anthropic saisie dans Réglages.
